# UNITEK — Qiymət Siyahısı

UNITEK məhsullarının premium qiymət siyahısı. Sayt GitHub Pages ilə avtomatik yayımlanır.

**Sayt:** https://kunalbehbud.github.io/unitek-qiymet-siyahisi/

## Necə yenilənir?

1. **UNITEK Manager** proqramında qiymətləri və məhsulları dəyişin.
2. **Production Update** düyməsini basın.
3. Proqram yeni `index.html` faylını bu repoya göndərir.
4. Sayt 1–2 dəqiqə ərzində avtomatik yenilənir.

## Vacib qeydlər

- Bu repo **açıqdır (public)**. Buraya yalnız `index.html` göndərilməlidir — verilənlər bazası, backup və ya şəxsi fayllar heç vaxt göndərilməməlidir.
- GitHub token-i yalnız bu repoya icazəli olmalıdır (Fine-grained token, `Contents: Read and write`). Token-i heç kimlə və heç bir AI söhbətində paylaşmayın.
